# Agent 优化计划

## 一、诊断鉴别优化

### 常见易混淆疾病对（根据训练数据分析）
1. **单纯疱疹病毒感染 vs 水痘 vs 卡波西水痘样疹**
   - 关键鉴别点：
     - 有无湿疹/皮损基础 → 卡波西水痘样疹
     - 全身散布水疱（非局限皮损区）→ 水痘
     - 局部簇状水疱 → 单纯疱疹
   
2. **尿道下裂 vs 卵睾性别发育异常（Ovotesticular DSD）**
   - 关键鉴别点：
     - 有无发育异常的其他表现（如隐睾、染色体异常）→ DSD
     - 单纯尿道口位置异常 → 尿道下裂

3. **肺炎 vs 支气管肺炎**
   - 需要更精确的解剖定位描述

### 优化方式
在 `SPECIALIST_CONSULT_PROMPT` 和 `ATTENDING_PHYSICIAN_PROMPT` 中添加"常见易混淆疾病鉴别指导"。

## 二、检查名称标准化优化

### 问题
- 检查名称过于具体（`软组织超声` vs `超声`）
- 遗漏基础检查（`体格检查`、`全血细胞计数（CBC）`）

### 优化方式
1. 在 `EXAM_ITEM_PROMPT` 中强化"优先使用通用/标准名称"
2. 添加"必须先考虑的基础检查清单"提示：
   - 体格检查（几乎所有病例）
   - 全血细胞计数（CBC）（感染/炎症/血液病）
   - 针对性病原学/影像学检查

## 三、特殊病例处理

### 新生儿/儿童发育异常
- 需要优先安排 `体格检查` + `超声` + `核型分析`
- 进行详细家族史询问

### 优化方式
- 在 SPECIAALIST_CONSULT_PROMPT 中针对儿科/发育科疾病增加专门指导

## 四、Token 效率优化

### 当前状态
- 每个患者约 15-20 次 LLM 调用
- 最耗 token 的是：info_gap（每次问诊都要调用）+ specialist×2

### 优化方式
1. **减少 info_gap 调用**：每 2 轮问诊才调用一次 info_gap 分析
2. **合并 specialist 调用**：尝试用一次调用同时产出两位专科意见
3. **缩短 memory_notes**：限制每条反思长度

## 五、Memory 管理优化

### 当前状态
- Memory 已有 34+ 个病例经验，但每轮都要全部加载（max_notes=10）

### 优化方式
1. 按科室分类存储经验
2. 检索最相关的历史病例（而不是全部加载）
3. 设置 `max_notes` 为 5（减少 token）
