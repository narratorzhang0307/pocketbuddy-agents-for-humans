# 练了吗 · 便携包使用说明（macOS Apple Silicon）

一个 AI 健身教练：实时姿势矫正 + 动作计数 + 文字教练（本地大模型）。
本包含移动端 App、模型服务（RTMPose + ST-GCN）、Ollama 文字教练，已适配 macOS 苹果芯片。

**两种使用方式，装一次、共用一套：**
- **电脑模式**（`start.command`）：网页运行，用**影石 Insta360** 外接摄像头。
- **手机模式**（`start-手机摄像头.command`）：手机装 Expo Go 扫码，用**手机自带摄像头**。

## 目标机器要求
- **macOS（Apple Silicon，M 系列芯片）**
- 已装 **Python 3.11+**（推荐 3.12）与 **Node.js 18+**；建议装 **Homebrew**（用来自动装 Ollama）
  - 没装的话：先装 Homebrew（https://brew.sh），再 `brew install python@3.12 node`
- 首次安装需要**联网**（会下载依赖 + 文字教练模型约 1.9GB）
- 电脑模式需要一个**影石 Insta360** 摄像头；手机模式需要一部**手机**（和电脑同一 Wi‑Fi）

## 第一步：一次性安装（两种模式都要先做这步）
双击 **`setup.command`**
- 首次可能被 macOS 拦截：右键点它 → 打开 → 确认；或到「系统设置 → 隐私与安全性」点「仍要打开」
- 自动完成：建 Python 环境、装依赖（含 PyTorch）、装 App 依赖、部署姿态模型、
  装 Ollama 并拉取文字教练模型 `qwen2.5:3b`。约 8-20 分钟。

---

## 方式 A：电脑模式（影石摄像头）
1. 双击 **`start.command`**
2. 自动起模型服务(:4000) + 文字教练 + App(:8082)，并用 Chrome 打开 `http://localhost:8082`
3. 在 **Chrome**（推荐）里：底部 **运动 → 选动作 → GO → 允许摄像头**
   - 会**自动锁定影石 Insta360**（不用 Mac 内置摄像头）
   - 站进画面做动作：中间数字实时计数，并给纠正提示
- 摄像头首帧需在弹窗点一次「允许」（浏览器安全机制，会被记住）

## 方式 B：手机模式（手机摄像头）
1. 手机装 **Expo Go**（App Store / 应用商店搜 Expo Go）
2. 手机连**和电脑同一个 Wi‑Fi**
3. 电脑双击 **`start-手机摄像头.command`**
   - 脚本自动探测电脑局域网 IP，把模型服务地址写好，并在终端里显示一个**二维码**
4. 扫码打开：
   - **iPhone**：用「相机」扫二维码 → 点弹出的 Expo 链接
   - **安卓**：打开 Expo Go → Scan QR code 扫码
5. App 打开后：**运动 → 选动作 → 训练页允许摄像头** → 用手机摄像头训练
- 结束：终端窗口按 **Ctrl+C**，再双击 `stop.command`

### 停止
双击 **`stop.command`**（两种模式通用）

---

## 文字教练（AI 对话/纠错文案）
由本地 **Ollama + qwen2.5:3b** 提供，`setup.command` 会自动装好，无需联网即可对话。
- 想换模型：改 `start.command` / `start-手机摄像头.command` 顶部的 `OLLAMA_MODEL`，
  再 `ollama pull 你选的模型`（如 `qwen2.5:1.5b` 更小、`gemma3n:e2b` 更强）。

## 影石摄像头说明（仅电脑模式）
App 内置摄像头选择补丁（`app_project/app/src/camera/preferredCamera.ts`）：
设备名含 `insta360` 就自动选它。可在 `app_project/app/.env` 改 `EXPO_PUBLIC_PREFERRED_CAMERA`。
> 手机模式用手机自带摄像头，这项不生效。

## 常见问题
- **双击脚本打不开 /「无法验证开发者」**：右键 → 打开；或系统设置→隐私与安全性→仍要打开。
- **手机扫码后连不上 / 一直转圈**：确认手机和电脑**同一 Wi‑Fi**；公司/学校网络可能隔离设备，
  换个人热点再试；或看终端里的 `exp://` 地址是不是电脑的局域网 IP。
- **手机上「帧分析失败」**：说明手机连不到电脑的模型服务(:4000)，多半是防火墙/不同网段。
  到「系统设置 → 网络 → 防火墙」允许 Python 接入，或关掉防火墙再试。
- **电脑模式「帧分析失败」**：模型服务(:4000)没起来，重跑启动脚本，或看 `/tmp/lianlema_model.log`。
- **文字教练报错**：Ollama 没起来。重跑启动脚本会自动拉起；或手动 `ollama serve` + `ollama pull qwen2.5:3b`。
- **端口被占用**：启动脚本会先杀旧进程；仍不行就重启机器。

## 目录结构
```
lianlema-portable/
├── setup.command              # 一次性安装（双击）
├── start.command              # 电脑模式启动 · 影石摄像头（双击）
├── start-手机摄像头.command    # 手机模式启动 · 手机摄像头（双击）
├── stop.command               # 停止（双击）
├── requirements-mac.txt       # 模型服务依赖（已固定版本）
├── assets_cache/              # 内置姿态模型（免下载）
└── app_project/               # 全部源码（App + 模型服务 + 权重）
```
