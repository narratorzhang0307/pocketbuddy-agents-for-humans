# 练了吗 · 启动说明

## 一键启动（推荐）

**双击 `启动.bat`** 即可。它会自动：
1. 检测本机当前 WiFi 的局域网 IP
2. 把 IP 写进 `app/.env`
3. 弹出两个窗口分别启动「模型服务」和「Expo」

> 换了 WiFi 后，**不用手动改任何文件**，重新双击 `启动.bat` 就会更新 IP 并重启。

## 启动后怎么用

- **手机**：连**同一个 WiFi**，打开 Expo Go → 扫「Expo」窗口里的二维码 → 进「运动 → 选动作 → GO」。
- **电脑浏览器**：在 Expo 窗口按 `w`，或访问 `http://localhost:8081`。
  - 注意：电脑浏览器用 `localhost` 才能开摄像头（局域网 IP + http 会被浏览器禁用摄像头）。

## 停止

关掉那两个新弹出的 PowerShell 窗口即可。

## 常见问题

- **手机连不上模型**：确认手机和电脑在同一 WiFi，且 WiFi 没开「AP 隔离/访客网络」。也确认电脑防火墙允许 4000 端口（首次运行 Python 时若弹防火墙提示，勾选「专用网络」并允许）。
- **IP 选错了**（比如选到 VPN 地址）：脚本优先选 WLAN。若仍不对，运行 `ipconfig` 查「无线局域网适配器 WLAN」的 IPv4 地址，手动填进 `app/.env` 的 `EXPO_PUBLIC_MODEL_BASE_URL=http://<IP>:4000`，再重启 Expo。
- **首次开始训练较慢**：RTMPose 模型已下载缓存到本机，正常；之后每帧很快。
- **教练语音文字报错**：需安装 Ollama 并 `ollama pull gemma4:e2b`（可选，不影响动作识别与姿势矫正）。
