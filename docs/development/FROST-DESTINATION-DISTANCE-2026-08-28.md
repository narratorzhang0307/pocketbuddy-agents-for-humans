## 输入语义与交接

- 「帮我规划下去西湖的跑步路线，三公里」表示从当前位置出发、到西湖结束，总程目标约 3 公里。
- 「在西湖附近跑三公里」表示在西湖附近规划；保留软件补充形状/偏好流程，硬件用默认条件。
- 目的地和里程均明确时，软件也直接创建地图任务，省略的偏好采用风景好、少路口；软件不会自行启动定位导航。真实 badge_voice 来源可以请求自动开始，首次权限、已存在导航、定位可靠性和路线误差检查仍保留。
- 支持任意合法距离值，含中文数字、阿拉伯数字、小数、公里半、米；支持时长和半小时/半个小时/一个半小时。当前有效距离 0.5–50 公里，时长 5–180 分钟；时长按约 7 分钟/公里估算。
- 「改成四公里」保留最近一次路线的起点、目的地和偏好，创建新路线会话。正在导航时不能静默替换路线，需先暂停或结束。

原模型把 distance/duration/destination 三者做成互斥，导致目的地覆盖里程。现有 destination goal 增加可选 target（distance 或 duration）；旧会话缺少 target 时兼容原行为。Taskmaster 同时传 destination 与 distance_m/duration_min，地图 metrics 保留目标距离。Qwen 仍用原 run-route-intent 接口，数量必须有原句证据，不能从无数量的“去西湖”虚构 3 公里。

## 真实道路规划

先查指定目的地及直达/往返道路。没有目标里程时维持直接规划；已有合适距离时复用真实道路。指定较长里程时，在起终点两侧提出途经点，以每次高德返回的实际步行总长校准下一次查询。最多两侧各四轮，单次任务内缓存相同方向的路段；往返的回程另查，不能把去程反转当证据。

所有地图折线来自完整、连接有效的高德步行步骤。坐标仅用于查询候选道路，不能直接画直线补长，不能改写高德距离去凑目标。

里程容差统一为 `max(100 米, 目标 × 5%)`。地图同时显示目标、规划距离及相差米数。不达标时显示 CHECK 和需确认提示，不会自动开始；底层导航入口也执行相同检查。若直达/往返道路已经超过目标，明确提示增加里程、换起点或改为在目的地附近跑，不静默忽略目标。

地图视野根据实际底部面板高度留白，避免新增距离说明遮挡起点；切换不同会话时重新适配整条道路。规划线与真实 GPS 轨迹继续分开保存。
