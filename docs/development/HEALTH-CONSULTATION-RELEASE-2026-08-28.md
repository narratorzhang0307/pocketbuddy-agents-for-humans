# 健康咨询语音入口与统一回复音量 · 2026-08-28

## 实现范围

- “医院 Agent”用户入口改为“健康咨询 Agent”，新增正式 Skill `frost.health-consultation`。旧“打开医院 Agent”说法仍兼容，直接打开咨询页，不再被通用 Frost 对话吞掉。
- 当前咨询页打开期间，B 板按住说话、松开传输：BLE PCM → iPhone 本机 ASR → 当前咨询的文本检索 + 云端 Qwen → iPhone TTS → BLE PCM → B 板扬声器。打开页面本身不会请求模型。
- 使用已有 `subagent:hospital-agent` 服务；本轮真实请求返回模型 `qwen3.8-max`。本地按问题检索现有 67 条疾病 Skill 中的问诊参考问题，返回最多三条可见来源；没有新建向量数据库，不把本地示例库当成经临床验证的资料。
- AI 身份和云端处理在页面及语音欢迎词中明确告知；不宣称医生身份，不输出确定诊断或处方剂量。仅提交本次问题、当前咨询上下文和所需参考段落，不自动上传健康账本。
- 咨询对话只在内存中存在，不写入 Frost 的持久聊天或健康账本。退出、离页、隐藏或 30 分钟闲置后结束；取消后的迟到结果不继续朗读。
- 咨询页和普通 Skill 回复统一使用与“练了吗”教练一致的硬件 `100 / 0 dB` 播放档；保持显式静音，并在停止/断开后恢复普通音量。未做 PCM 暴力放大。相同档位不代表不同音源的实测响度完全相同。
- 固件 `0.2.23-reply-volume` 增加真实扬声器开始/排空的音量记录，保留 10 秒识鸟录制和 PSRAM 音频缓冲修复。
- 保留小狗眨眼图标、桌面组件/灵动岛、Photos 可移除示例、新线稿画布及现有 Skills。
