## 本轮交付

保留原小狗、240×240 满幅圆屏构图与离线回退。通过内置 image_gen 编辑生成小开口、张嘴、眨眼三张表情帧，原图不覆盖；工具未返回模型版本。

- 预览：`public/assets/frost-talk/20260828/index.html`。
- 循环动图：同目录 `frost-speaking.gif`、`frost-speaking.webp`，360×360、25 帧、5.14 秒。
- 编辑原件：同目录 `originals/`；完整提示词：`prompts.json`。
- 板端素材：同目录 `hardware/`，三张新增 JPEG 共 45,868 字节；静态帧复用原来的 14,126 字节 JPEG。
- 导出命令：`node scripts/hardware/build-frost-talk-assets.mjs`。仅格式转换、动画组装和预览圆形裁切，不程序绘制小狗，不修改既有头像 generator/catalog。

GIF 是节奏示意，不是实机录屏，也不包含录音。预览页支持静态对比和减少动态效果偏好。

## 固件接法

`OjBadgeAudio` 只在 PCM 成功提交到扬声器 codec 后更新声量；不使用麦克风，不因“正在思考”触发。按平均绝对振幅选择小嘴/张嘴，并加短促闭嘴与 120 ms 眨眼。这是音量驱动动效，不是逐字音素口型同步；I2S DMA 带来不超过约 90 ms 的已有缓冲延迟，需上板确认观感。

静音或数据中断最多保留 100 ms 尾音后回到原图。显式停止、录音、断连、远程头像显示、远程头像上传、现有特殊模式期间不播放小狗动效。诊断提示音不触发嘴型。

仅 index 0 使用新增表情；其他 29 项标签和远程头像机制不变。JPEG 在现有双缓冲之间解码切换，没有新增整屏缓冲，没有持久化 Flash 写入。原有按住录音权限与输入逻辑未改。
