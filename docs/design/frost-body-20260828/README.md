# Frost 身体轻摇与呼吸 · 0.2.20

已烧录 `0.2.20-ojbadge-frost-body`。沿用原来的五张小狗表情，对头像图层围绕身体下方锚点轻微旋转、缩放，模拟摇摆和呼吸；圆屏边框、提示文字保持固定。单双眼表情交替，仍各停留约 1.6 秒。

## 动效与范围

- 4.8 秒一循环，左右各 0.8°；缩放为 260–264 / 256，适度扩大来保持圆屏满幅。
- 固定锚点 `(120,210)`，姿态更新间隔至少 80 ms；实际速度受 JPEG 解码和 UI 绘制影响，网页预览不是实机录像。
- 眯眼保持期间，身体继续轻摇。录音、远程头像上传、其他技能头像及专用显示模式暂停动作并恢复 1:1。
- 无新增图片，也无新增常驻整屏缓冲；使用 LVGL 现有图像变换。原小狗、五张 JPEG、30 个头像标签和 OSS catalog 哈希未变。
- LVGL 每次切换图片会重置旋转锚点，固件在换嘴型/眼睛后重新设置，避免构图跳动。

预览：[index.html](../../../public/assets/frost-talk/20260828/index.html)。`frost-speaking.gif` 仍是原表情循环，不含本次身体变换。网页已检查循环和静态对比按钮、姿态变化；截图为 `browser-preview.png`。
