# Frost 轻交互入口与手机共用能力 · 2026-08-27

## 分工与唯一入口

吧唧不是另一套主 Agent，也不保存云模型密钥。它承担麦克风采集、实体操作、表情显示、扬声器播放；手机承担本机 ASR、会话、记忆、Taskmaster、权限和 Skill 页面。已有服务端继续承担原来的云模型及连接器，不为蓝牙或本机 ASR 新增服务器依赖。

```text
吧唧实体录音 → Agent_link / BLE → 完整 PCM（手机内存）
  → 默认：用户点击本机 ASR → 核对草稿 → 手机发送
    或：显式开启本次前台语音对话 → 新录音本机 ASR → 自动发送文字
  → sendFrostAgentMessage(text, {channel: badge_voice, inputId})
  → 原 Frost 会话 / 同一能力目录 / 原 Taskmaster 与各 Skill 权限门
  → 真实主会话事件 → App 级 FrostCompanion → 吧唧表情
  → 同一轮回复 → iOS 系统中文 TTS → 16k PCM16 → 原 BLE/L2CAP → 吧唧扬声器
```

音频 16 kHz、单声道 PCM16，最多 30 秒。iOS 检查 `supportsOnDeviceRecognition`，强制 `requiresOnDeviceRecognition = true`；中文本机识别不可用、权限拒绝、失败或 45 秒超时都明确失败，不改走云端。仅最终文字可进入草稿；删除录音、取消、换录音会丢弃旧识别结果。关闭 App 后内存录音不保留。

文字在手动发送或用户开启前台语音对话后走现有模型链，可能发送到云端；不承诺“全部推理离线”。MiniMax 文本转语音仍保持手动点击与费用提示。自动朗读只使用已安装的 Apple 系统中文声音，不请求付费 TTS/ASR；每次最多 100 字、30 秒 PCM，合成超时 20 秒，传输超时 45 秒。长回复截短并提示在手机阅读全文。

语音对话开关仅在当前 App 前台连接生效，默认关闭、不持久保存。开启时不处理旧录音；录音不完整、有丢包或峰值为 0 时不会自动识别或发送。新录音中断旧识别/朗读；主 Agent 忙时不会排队第二条自动语音。后台、断连、主会话切换会关闭开关，回到前台不会自动恢复。已发送的任务不会因关闭开关而撤销，执行结果仍保留在手机。任何失败都不自动重试。

## 会话、输入与安全

- `src/main.tsx` 原生 App 启动应用级桥，不随 Frost 页面卸载；不自动扫描、连接、录音或调用模型。
- `frostAgentRuntime.ts` 发布当前主会话的只读事件和完成轮次；手机聊天页同时观察语音输入和回复，没有第二个硬件主循环、记忆库或 Taskmaster。离开能力页再回 Frost 时恢复同一轮计划，不自动重开页面。
- Frost 对话页前台，手机文字与吧唧 ASR 共用完成通知及 `frostAgentNavigation.ts` 页面交接；「帮我调用健身agent」走已部署的练了吗（`pocket.lianlema`，HTTPS `/lianlema/`），不当作默认十分钟 Her Motion 训练。此映射在 19:32 用户发现旧 `/her-motion/` 回退主站后修正；旧映射不能当验收结果。单个已装备能力准备成功后可自动进入，重复完成通知不重复跳转；后台和历史恢复不自动打开。
- 每次 BLE 连接有新 ID，每段录音有独立 ID；触摸去重，录音并发/重复发送去重。断开后迟到的外围输入被忽略。
- `peripheral.input` 只记来源、类型、计数/字节数；不存 PCM，不进入用户指令队列，不唤醒模型，也不代表授权或完成。
- 识别出的通用“确认”不能签发 Taskmaster 权限凭证。用户已明确要求健身启动命令沿用旧入口，无需新增手机确认按钮，因此该启动入口可确认自己的 Her Motion 任务；不扩大到其他任务的授权。iOS 摄像头系统权限、导入和保存等原权限仍保留。
- 表情根据实际运行、等待、录音、停止等状态投射；只有当前用户、当前会话的真实 Taskmaster 完成观察，或匹配主会话交接的页面实际结果可触发完成提示。模型说“完成”、子 Agent 准备交接和触摸都不是完成证据。
- 历史恢复不重放声音；后台不主动发送表情/提示音；回到前台或重连时只同步当前表情。传输错误只影响外围显示，不修改任务真值。
