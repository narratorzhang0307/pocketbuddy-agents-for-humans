# 吧唧语音 → 真实 GPS 地图种树

## 使用

1. 在现有 Frost 页面连接吧唧，保持“松手自动识别并发送”开启。
2. 保持手机 App 前台，按住吧唧**实体键**说“进入地图模式”，松手结束。手机自动切到中间 Earth 的地图，固定选男主、默认小狗和牵绳，不继承之前的女主/多宠物选择，不需要打开选择页或装种子。
3. 自动请求手机真实 GPS；首次使用须在手机允许系统定位权限。定位样本有效、完成高德坐标转换后，吧唧才回复“定位已就绪，可以种树了”。地图是男主牵默认小狗的真实定位画面。再按实体键说“帮我种下一颗树”，也接受“一棵树”。观鸟模式下长按触屏仍是录鸟叫，不是这两条语音指令。
4. 当前 GPS 位置出现一棵枇杷树，复用现有生长动画、出生牌和本机种植记录；地图显示结果，吧唧尝试本机朗读结果。

这是地图中的数字纪念树，不代表现实植树，也不会发布到服务器。语音纪念树不消耗种子、不改步数或种子奖励；手动种植流程保持原样。

## 边界

- 只认本次硬件录音的完整种树命令，不匹配否定、疑问、引用、未来计划或复合命令。
- 仅中间 Earth 的真实地图挂载期间开放入口；切离地图、结束散步、后台、演示路线均不能执行。
- 使用散步定位过滤器接受、已转换为高德坐标的 GPS 样本；不使用镜头中心、角色位置或预览路线。
- 样本必须在过去 15 秒内且精度不超过 ±65 米；无定位、弱信号、坐标转换失败、定位报错时不落点。异步旧定位不能覆盖模式切换/错误后的状态。
- 同时保存地图坐标、WGS84 坐标、定位精度、采样时间和录音事件编号；不保存录音或指令文本。
- 同一录音去重；被拒绝的命令不会等 GPS 恢复后自动执行，必须重新按键说话。
- 写入后读回确认，失败不会报告成功。朗读失败不重复种树，也不转交云端 Agent。
- 复用观鸟链路的前台语音转交；原生黑屏观鸟保持原样。此功能不新增黑屏种树能力。
- “进入地图模式”仅从本次完整录音发起，直接本机处理，不进入云端聊天。等待地图懒加载和 GPS 最长 45 秒；打开页面本身不算定位成功。
- 进入地图固定选现有男主 `wayfarer-guide-rigged-map-v1` 和默认腊肠狗的真实骨骼模型，`leash` 模式、无额外口袋搭子、`gps` 定位。已在这一组合的有效 GPS 散步中时，只回到当前位置，不重置路程。
- 定位权限拒绝或不可用时，语音入口停止等待，不自动改成演示路线。定位过程中离开页面/切换模式、断连、关闭自动语音、退后台或开始新录音，会取消本次等待；迟到的 GPS 不能再触发成功播报。
